# Sistema de Gestión Logística y Ventas - Corporación Rubio S.R.L. (Rubio Store)

Proyecto de ingeniería de software enfocado en el análisis, modelado y diseño de una solución tecnológica para optimizar los procesos operativos y comerciales de **Corporación Rubio S.R.L.** (empresa dedicada a la venta de EPPs y artículos de seguridad industrial)[cite: 1.2, 1.5].

## 🚀 Resumen del Proyecto
El sistema busca resolver las deficiencias en la gestión de pedidos, control de inventarios y distribución, conectando de manera eficiente las áreas clave de la empresa:
- **Área de Ventas:** Gestión y recepción de pedidos de clientes[cite: 1.3].
- **Área de Almacén:** Administración de stock, inventariado y preparación de despachos[cite: 1.3].
- **Área de Distribución:** Control de rutas y logística de entrega[cite: 1.3].
- **Gerencia:** Visibilidad de procesos operativos para la toma de decisiones estratégicas[cite: 1.3].

## 🛠️ Enfoque y Arquitectura
- **Modelado del Negocio:** Definición de actores (Stakeholders), casos de uso del negocio y análisis de problemas (diagramas de causa-efecto / Ishikawa).
- **Arquitectura de Software:** Selección y evaluación de alternativas de solución bajo restricciones realistas de ingeniería[cite: 1.5].
- **Herramientas de Ingeniería:** Modelado y documentación técnica orientada a un entorno comercial y mayorista/minorista de ferretería y seguridad[cite: 1.2, 1.5].

## 👥 Equipo de Desarrollo
Proyecto desarrollado en el marco de los cursos de Ingeniería de Software / Diseño y Arquitectura de Software[cite: 1.2, 1.5].
